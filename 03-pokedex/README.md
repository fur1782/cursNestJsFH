# Executar en desenvolupamnet

1. Clonar el repositori
2. Executar
```bash
yarn install
```

3. Tenir Nest CLI instal·lat globalment
```bash
npm i -g @nestjs/cli
```

4. Aixecar la abase de dades
```bash
docker compose up -d
```
