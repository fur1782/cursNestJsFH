# Teslo API

1. Clonar el projecte
2. ```pnpm install```
3. Clonar l fitxer ```.env.template``` i renombra-lo a ```.env```
4. canviar les variables d'entorn
5. Aixecar la base de dades
```bash 
docker compose up -d
```
6. Aixecar: ```pnpm start:dev```
